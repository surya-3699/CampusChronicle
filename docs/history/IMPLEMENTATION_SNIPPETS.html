🎨 Step 7: Customize Colors & Effects

7

Override CSS Variables in your custom CSS:

/* Change glow color */
:root {
    --glow-cyan: rgba(0, 229, 255, 0.2);      /* Primary glow */
    --glow-cyan-bright: rgba(0, 229, 255, 0.35); /* Bright glow */
}

/* Adjust blur intensity */
:root {
    --glass-blur: 12px;           /* Button blur */
    --glass-blur-heavy: 16px;     /* Card blur */
}

/* Change primary surfaces */
:root {
    --glass-surface-light: rgba(255, 255, 255, 0.08);
    --glass-surface-medium: rgba(255, 255, 255, 0.12);
}

/* Custom button override */
.btn-primary {
    background: rgba(0, 137, 166, 0.30) !important;
}

.btn-primary:hover {
    background: rgba(0, 200, 220, 0.40) !important;
}

⚡ Step 9: Optimize Performance

9

Performance Best Practices:

<!-- 1. Add loading="lazy" for images -->
<img src="image.jpg" loading="lazy" alt="Description">

<!-- 2. Preload video for better performance -->
<link rel="preload" as="video" href="background.mp4">

<!-- 3. Optimize video file size -->
<!-- Use HandBrake or FFmpeg to reduce file size -->

<!-- 4. Add CSS containment -->
<style>
    .video-bg-container {
        contain: layout style paint;
    }
</style>

<!-- 5. Use smaller blur on mobile -->
<style>
    @media (max-width: 768px) {
        :root {
            --glass-blur: 8px;  /* Reduced from 12px */
        }
    }
</style>
⚠ Important: Keep video file size under 2MB for homepage for optimal performance!
